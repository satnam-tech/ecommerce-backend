# 🛒 ShopSphere — E-commerce Backend API

A production-oriented REST API for an e-commerce platform with authentication, product management, cart, orders, payments, search, filtering, and image management.

---

## 🚀 Features

- 🔐 User Authentication with OTP Verification
- 👤 User & Admin Authorization
- 📦 Product & Category Management
- 🔎 Search, Filtering & Sorting
- 🛒 Cart & Cart Item Management
- 📍 User Address Management
- 📋 Order & Order Item Management
- 💳 Razorpay Payment Integration
- 🖼️ Cloudinary Image Uploads
- 🔒 Protected Routes & Ownership Checks
- ⚡ RESTful API Architecture

---

## 🛠️ Tech Stack

**Backend:** Node.js, Express.js  
**Database:** MongoDB, Mongoose  
**Authentication:** JWT, OTP, Twilio  
**Payments:** Razorpay  
**Image Storage:** Cloudinary  
**Development:** Prettier, Postman
